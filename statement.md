# Project Statement

## Project Title

DriveEase Vehicle Rental Management System

## Problem Statement

Traditional vehicle rental operations often depend on manual records for vehicles, customers, rental dates, returns, and payments. This can cause duplicate bookings, incorrect billing, difficulty tracking vehicle availability, and loss of rental information.

DriveEase provides a computerized solution for managing vehicle rental activities in an organized and reliable manner.

## Scope

The project manages:

- Vehicle registration and availability
- Customer registration
- Rental booking
- Vehicle return processing
- Late fee calculation
- Invoice generation
- Rental record storage

The project is designed for small and medium-sized rental agencies.

## Target Users

- Rental company administrators
- Rental staff
- Vehicle managers
- Customers indirectly using the rental service

## Objectives

- Reduce manual rental records
- Improve vehicle availability tracking
- Automate rental cost calculations
- Reduce billing errors
- Store customer and rental data securely
- Demonstrate Java OOP concepts

## High-Level Features

- Vehicle CRUD operations
- Customer management
- Rental booking
- Vehicle return
- Automatic late fee calculation
- Invoice generation
- SQLite database integration
- Validation and error handling
